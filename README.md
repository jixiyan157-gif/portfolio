# AI 视觉设计师 · 个人作品集

暗色沉浸、采用莓红与青绿色染光渐变的响应式个人作品集。前台为纯静态页面（HTML + CSS + 原生 JS），项目展示由轻量 Node.js 后端驱动，后台可随时增删改项目，无需数据库。

## 快速开始

```bash
cd portfolio/server
npm install          # 首次运行需安装依赖（约 1 分钟）
npm start            # 启动服务
```

启动后访问：

| 地址 | 说明 |
|---|---|
| http://localhost:3000 | 前台网站 |
| http://localhost:3000/admin/ | 作品集后台（默认密码 admin123） |

**修改后台密码**（建议首次启动后立即执行）：

```bash
npm run set-password -- 你的新密码
```

**不启动后端也能预览**：直接双击 `index.html`，项目区会展示内置演示项目（用于排版预览）。启动后端后，前台自动读取真实项目；项目为空时显示空状态提示。

## 离线单文件版

生成一个**无需联网、任何设备浏览器直接打开**的单文件网页（含全部页面、3D 画廊、three.js、项目图片）：

```bash
# 先启动后端（离线版会打包当前后台里的真实项目）
cd server && npm start
# 另开终端，在 portfolio 目录运行
python build_offline.py
```

生成文件：`作品集离线版.html`（约 1.3MB）。复制到手机/平板/U 盘，用浏览器打开即可，完全离线可用。

注意：项目内容更新后（后台新增/修改项目），重新运行 `build_offline.py` 即可刷新离线版。

## 后台使用说明

- **新增项目**：右上角「新增项目」→ 填写标题（必填）、分类、年份、一句话描述、工具标签（逗号分隔）、上传图片（必填）→ 保存
- **编辑项目**：列表点击「编辑」，不重新选择图片则保留原图
- **删除项目**：列表点击「删除」，项目数据与图片文件一并删除
- 前台项目按发布时间倒序展示，瀑布流自动适配图片比例

### 接口一览

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| GET | /api/projects | 项目列表（倒序） | 公开 |
| POST | /api/login | 密码登录，返回 token | 公开 |
| POST | /api/logout | 退出登录 | 需要 |
| POST | /api/projects | 新增项目（multipart，含图片） | 需要 |
| PUT | /api/projects/:id | 更新项目（图片可选） | 需要 |
| DELETE | /api/projects/:id | 删除项目及图片 | 需要 |

登录后 token 存浏览器 localStorage，有效期 12 小时；后端重启后需重新登录。

## 内容结构

页面整体叙事围绕「一次生成」展开：**噪声 → 点击生成 → 结构浮现**。

| 层级 | 板块 | 表达目标 |
|---|---|---|
| 入口页 | 生成控制台 | 大标题「生成」+ prompt 行 + 粒子噪声场，点击后粒子聚拢，主站浮现 |
| 1 | 首屏 Hero | 3D 唱片画廊背景（封面取后台项目图片）+ 一句主张「把想象，变成视觉」+ 双 CTA |
| 2 | 个人经历 | 头像、自我介绍（两段）、四项项目数据、邮箱/微信/小红书 |
| 3 | 精选项目 | 瀑布流展示，图片按原始比例呈现，三列（桌面）/ 两列（平板）/ 单列（手机） |
| 4 | 个人优势 | 按「我擅长 / 我如何工作 / 我解决什么」三栏，每栏两条 |
| 5 | 页尾联系区 | 完整收尾：一句主张 + 邮件 CTA + 社交入口 + 版权栏 + 返回顶部 |

导航锚点：关于 `#about`、项目 `#works`、优势 `#strengths`、联系 `#contact`。

## 设计规范

### 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0a0c10` | 页面底色（深蓝黑） |
| `--bg-2` | `#0f1218` | 卡片 / 配图底色 |
| `--bg-3` | `#151a24` | 面板提亮 |
| `--text` / `--text-2` / `--text-3` | `#e9ebf1` / `#9ba3b2` / `#5f6774` | 三级文本层级 |
| `--accent` | `#8b8fff` | 主点缀（紫罗兰）：句点、标签短线、交互反馈 |
| `--accent-2` | `#5fd9ff` | 次点缀（青）：粒子场与配图光效 |

原则：点缀色只出现在「小标记 + 交互状态」上，正文不染色；按钮主色为白色（深色字），克制而高级。

### 字体

- 正文/标题：`Chivo`（拉丁）+ 系统中文黑体栈（PingFang SC / HarmonyOS Sans SC / Microsoft YaHei）
- 技术性文本：`IBM Plex Mono` —— 仅用于 SEED、prompt、工具标签、数据数字等「工作流语境」内容
- 字体经 `fonts.loli.net` 镜像加载（中国大陆可访问）；离线时自动回退系统字体

### 字号与间距

- 标题：Hero `clamp(46px → 96px)`，章节 `clamp(30px → 42px)`，入口大字 `clamp(88px → 190px)`
- 正文 16px / 行高 1.9（中文阅读）；辅助文本 13–14px
- 圆角统一 `4px`，按钮为胶囊形；分隔线统一 `1px rgba(255,255,255,.08)`

### 断点

| 断点 | 行为 |
|---|---|
| ≥1021px | 完整桌面布局：经历左右分栏、瀑布流三列、优势三栏 |
| 1020–901px | 经历改为上下排布，头像收窄至 340px；瀑布流三列 |
| ≤900px | 导航收起为汉堡菜单；瀑布流两列（≥620px）；优势单列 |
| ≤640px | 瀑布流单列；Hero 双按钮全宽；数据两列；页尾版权栏纵向 |

### 动效原则

- 全站只有两处编排动效：入口点击后的「生成」过渡（粒子聚拢 + 闪光 + 主站浮现）、首屏 3D 唱片画廊（鼠标旋转视差 + 光标灯光跟踪，触摸可拖动旋转）
- 其余仅保留响应交互的反馈（hover、菜单开合）
- 尊重 `prefers-reduced-motion`：关闭动画与粒子循环，只绘制静态帧

### 首屏 3D 唱片画廊（js/hero-gallery.js）

- 复刻 unicorn.studio「CD Gallery」参考视频：暗场中 4 张**大尺寸**唱片横向排列、纵深错落（近大远小），唱片为亮色封面 + 白色中心轴
- 交互：桌面鼠标左右移动 → 画廊横向滚动跟随 + 相机微视差 + 点光扫过唱片；移动端横向滑动 → 惯性滚动（纵向滑动交给页面）
- **封面自动取后台项目图片**（前 4 张）；无后端或无项目时使用程序生成的亮色占位封面
- three.js 按序从 npmmirror → jsdelivr → unpkg 加载；全部失败或 WebGL 不可用时自动回退原粒子背景
- 窄屏保持唱片大尺寸、靠滑动浏览；标题带阴影保证可读

## 占位内容替换清单

前台静态占位（替换位置在 `index.html` 中以 `<!-- ⚠️ 待替换 -->` 注释标出）：

1. **姓名**：关于区标题 `[你的名字]`、页尾版权行
2. **头像**：关于区 SVG 占位图 → 真实照片（建议 4:5）
3. **联系方式**：导航「开始合作」、关于区、页尾的邮箱 `hello@yourname.com`、微信、小红书、站酷
4. **项目数据**：120+ / 40+ / 5 / 3× 四项统计 → 真实数据
5. **Hero 坐标**：`31.2°N 121.5°E`（上海）→ 真实所在地，或删除
6. **备案号**：页尾 `沪ICP备XXXXXXXX号` → 上线前补全或删除
7. **SEED**：`js/main.js` 顶部 `SEED` 常量，改成任意数字得到不同粒子画面
8. **入口特效**：内置的「生成」粒子特效；如有自己的特效代码可替换整合

项目内容不再需要改代码：全部在 **后台** 增删改。

## 部署提示

- **上线**：整站部署到任意 Node.js 主机（如宝塔 + PM2：`npm start` 常驻运行），前端、后台、接口同源部署，无需额外配置
- **端口**：默认 3000，可用环境变量 `PORT` 修改
- **安全**：上线前务必修改默认密码；上传接口限制图片格式与 15MB 大小；`server/` 目录已屏蔽外部访问
- **数据备份**：项目数据即 `server/data/projects.json`，图片在 `uploads/`，定期备份这两个位置即可
- **静态托管**（GitHub Pages 等）：仅托管静态文件时后台不可用，项目区会展示演示数据；如需后台功能请使用 Node.js 主机
